# Settings available

- DPI: seven fixed selections 400/800/1200/2400/3200/4000/4800; no editable stage values/count.
- Polling: 125/250/500/1000 Hz.
- Lighting: corrected static #rrggbb. Exact hardware R,B,G order fixes the vendor UI's green/blue swap.
- Standard button remapping: six physical buttons, left/right/middle/back/forward/DPI-cycle actions. Last primary click protected; unknown/macros preserved.
- Avatar: owner-requested mouse rendering.
- Native Windows companion: pointer speed, Enhance pointer precision, scroll lines/page scrolling, double-click interval. These are Windows user settings, not mouse firmware fields.

Other animated effects, light speed/brightness, DPI indicator colour editing,
macros/M-Macro and vendor host-profile tiles are not implemented. OpenMouse's own
host game profiles/setup import-export remain separate from hardware profile banks.
See testing.md for specific tested values and limits.
